# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-07

### Added
- Property listings with filtering and search
- Property detail pages with image gallery and interactive map
- Agent profile pages
- Favorites functionality (localStorage-based)
- Interactive map view with Yandex Maps
- Multilingual support: Armenian (`/hy`), Russian (`/ru`), English (`/en`)
- Yandex Maps geocoding and Nominatim district lookup
- TouchEstate PHP SDK integration
- MIT License
- CONTRIBUTING, SECURITY, CODE_OF_CONDUCT documentation
- GitHub Actions CI (PHP CS Fixer + PHPStan)
- Dependabot for automated dependency updates
